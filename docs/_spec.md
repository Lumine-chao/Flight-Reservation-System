**1 项目概述**

**1.1 项目背景**

航班预订系统（Flight Reservation
System）是一套面向终端旅客的在线机票预订平台。旅客自行注册账号后，可完成航班查询、下单预订、订单管理与取消等全部操作，无需再通过人工柜台或第三方代为办理。

系统覆盖注册登录、航班查询、下单预订与订单管理四大功能域。本文档围绕旅客自助购票的产品定位，对需求进行结构化整理与规则化描述，作为后续设计、开发、测试与验收的统一依据。

**1.2 项目目标**

  ------------------------------------------------------------------------------------------------------------------------
  **编号**   **目标**                                 **衡量方式**
  ---------- ---------------------------------------- --------------------------------------------------------------------
  G-01       让客户可自助完成注册、登录与预订全流程   注册、登录、下单、查单、改单、取消 6 条主链路全部可自助完成

  G-02       保障客户账号与订单数据的安全性           密码与安全问题答案加密存储；客户仅可访问本人订单；连续失败自动锁定

  G-03       实现订单全生命周期管理                   订单状态机覆盖已出票至已完成 / 已取消的全部流转

  G-04       通过强校验规则保证录入数据合法           用户名、密码、航班日期、起终点、乘机人等字段均有明确校验与友好提示

  G-05       保证订单唯一性与数据一致性               订单号全局唯一不可改；取消订单不做物理删除，记录完整可追溯

  G-06       交互友好、提示明确                       所有异常场景均给出可读的中文提示语，不出现系统级报错
  ------------------------------------------------------------------------------------------------------------------------

**1.3 项目范围**

- 账号模块：注册（含安全问题设置）、登录、用户名与密码校验、登录失败锁定、通过安全问题重置密码。

- 订单模块：新建订单、我的订单列表、打开订单详情、更新订单、取消订单。

- 配套能力：航班查询与选择、舱位与票数计算、订单号生成、订单状态机、提示语与异常处理。

**2.1 典型场景**

1.  新用户首次使用：打开首页 → 注册（用户名 + 密码 + 确认密码 +
    安全问题与答案）→ 注册成功自动登录。

2.  查询与下单：填写出发地、目的地与日期 → 浏览航班列表 → 选择航班与舱位
    → 填写乘机人信息 → 提交订单 → 预订成功并生成订单号。

3.  管理订单：进入「我的订单」→ 按状态筛选 → 打开订单详情 →
    修改订单信息或取消订单。

4.  忘记密码：登录页点击「忘记密码」→ 输入用户名 →
    回答注册时设置的安全问题 → 设置新密码 → 重新登录。

  BR-18          订单           订单归属当前登录客户，仅本人可见                 访问他人订单时提示「订单号不存在」，不泄露订单存在性

  BR-19          订单           仅已出票且航班日期未到的订单可修改               其他状态修改时提示「该订单不支持修改，如需变更请先取消后重新预订」

  BR-20          订单           取消订单需二次确认                               未确认前订单状态不变

  BR-21          订单           取消不做物理删除                                 状态变更为已取消，记录保留可追溯

**5 核心业务流程**

**5.1 注册流程**

5.  在登录页点击「注册」，进入注册页。

6.  输入用户名，实时校验长度、组成与首字符（BR-01～BR-03）；失焦时校验是否被占用（BR-07）。

7.  输入密码，实时校验长度与字符组成（BR-08）。

8.  再次输入确认密码，校验两次输入一致（UR-03）。

9.  从预设列表中选择安全问题并填写答案，校验必填性（BR-09）。

10. 全部通过则创建账号，自动登录并跳转首页；任一不通过则给出对应提示并停留在注册页。

**5.2 密码重置流程**

11. 登录页点击「忘记密码」，进入重置页。

12. 输入注册时使用的用户名，系统校验是否存在（UR-08）。

13. 系统回显该用户名注册时设置的安全问题，客户填写答案（UR-09）。

14. 校验答案：忽略大小写与首尾空格后比对；一致则进入下一步，不一致则提示并累计错误次数（BR-10）。

15. 连续答错 3 次：当日禁止该用户名继续重置，提示稍后再试（UR-11）。

16. 答案校验通过后设置新密码，校验强度规则与是否与当前密码相同（UR-12）。

17. 重置成功：写入新密码密文，该用户全部已签发令牌失效，跳转登录页（UR-13）。

**5.3 登录流程**

18. 打开系统，展示「航班预订登录界面」。

19. 检查账号是否处于锁定状态，锁定中则提示剩余解锁时间并终止。

20. 输入用户名与密码，点击「确定」。

21. 校验用户名：为空 → 提示「请输入用户名」并终止；格式非法 → 按
    BR-01～BR-03 提示并终止。

22. 校验密码：为空 → 提示「请输入密码」并终止；比对不通过 → 失败计数加
    1。

23. 若失败次数小于
    4：提示「密码错误，请重试」及剩余次数，清空密码框并定位光标，返回第
    3 步。

24. 若失败次数达到 4：锁定账号 15 分钟，提示锁定信息。

25. 校验通过：进入系统首页，失败计数清零。

**5.4 下单流程**

26. 登录成功后进入首页，填写出发城市、到达城市与航班日期。

27. 系统按条件筛选可预订航班并展示列表（含航班号、起降时间、航空公司、各舱位价格）。

28. 选择航班，系统自动带出航班详情与价格。

29. 按需调整机票数与舱位，系统自动重算总价（BR-14、BR-15）。

30. 填写乘机人姓名，否则提交按钮保持不可用（BR-16）。

31. 点击提交，系统生成唯一订单号，订单进入「已出票」状态并展示预订成功与订单号。

**5.5 订单管理流程**

32. 进入「我的订单」，系统仅返回当前登录客户的订单（BR-18）。

33. 按状态筛选或直接打开某条订单查看详情。

34. 已出票且航班日期未到的订单：可修改订单内容（BR-19），修改后金额按新规则重算。

35. 点击「取消订单」→ 二次确认 →
    确定则状态变更为已取消（BR-20、BR-21）。

36. 航班日期过后的未取消订单：由系统自动置为「已完成」，客户仅可查看。
